# 生产线上问题处理 - 总览

## 1. 生产问题分类

```
生产问题分类体系:

┌─────────────────────────────────────────────────────────────┐
│                    生产问题分类                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  系统资源类:                                                │
│  ├── CPU 飙高: 死循环、频繁GC、锁竞争、计算密集            │
│  ├── 内存溢出: 内存泄漏、大对象、堆外内存、元空间           │
│  ├── 磁盘问题: 磁盘打满、IO瓶颈、inode耗尽                 │
│  └── 网络问题: 连接超时、端口耗尽、网络风暴                 │
│                                                             │
│  JVM 类:                                                    │
│  ├── GC 问题: 频繁Full GC、GC停顿过长                      │
│  ├── 类加载: 类冲突、类加载泄漏                             │
│  └── 线程问题: 死锁、线程泄漏、线程池耗尽                   │
│                                                             │
│  数据库类:                                                  │
│  ├── 连接问题: 连接池耗尽、连接泄漏                         │
│  ├── 慢查询: 索引失效、全表扫描、锁等待                     │
│  └── 主从延迟: 复制延迟、数据不一致                         │
│                                                             │
│  中间件类:                                                  │
│  ├── Redis: 缓存穿透/击穿/雪崩、内存溢出                    │
│  ├── MQ: 消息堆积、消费失败、重复消费                       │
│  └── Nginx: 502/504、负载不均、连接超时                     │
│                                                             │
│  应用类:                                                    │
│  ├── 接口超时: 慢查询、外部调用阻塞                         │
│  ├── 线程池满: 任务堆积、拒绝策略                           │
│  └── 异常频发: NPE、参数异常、业务异常                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 问题排查通用流程

```
生产问题排查流程:

┌─────────────────────────────────────────────────────────────┐
│                    问题排查流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 快速止血                                                │
│  ├── 确认影响范围                                           │
│  ├── 重启服务（临时）                                       │
│  ├── 回滚版本（代码问题）                                   │
│  ├── 扩容（流量问题）                                       │
│  └── 限流降级（保护核心链路）                               │
│                                                             │
│  2. 信息收集                                                │
│  ├── 监控指标（CPU/内存/IO/网络）                           │
│  ├── 应用日志（错误日志、慢日志）                           │
│  ├── 链路追踪（调用链、耗时分布）                           │
│  └── 线程/堆转储（jstack/jmap）                             │
│                                                             │
│  3. 问题定位                                                │
│  ├── 分析日志和监控                                         │
│  ├── 定位问题代码                                           │
│  ├── 复现问题（测试环境）                                   │
│  └── 确认根因                                               │
│                                                             │
│  4. 修复验证                                                │
│  ├── 制定修复方案                                           │
│  ├── 开发修复代码                                           │
│  ├── 测试验证                                               │
│  └── 灰度发布                                               │
│                                                             │
│  5. 复盘总结                                                │
│  ├── 问题根因分析                                           │
│  ├── 改进措施                                               │
│  ├── 监控告警完善                                           │
│  └── 文档沉淀                                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 3. 常用排查工具

```
排查工具速查表:

┌──────────────┬──────────────────────────────────────────────┐
│ 场景         │ 工具                                          │
├──────────────┼──────────────────────────────────────────────┤
│ CPU 飙高     │ top -Hp, jstack, arthas                      │
│ 内存问题     │ jstat, jmap, MAT, arthas                     │
│ 磁盘问题     │ df, du, iostat, lsof                         │
│ 网络问题     │ netstat, ss, tcpdump, ping                   │
│ 线程问题     │ jstack, arthas thread                        │
│ GC 问题      │ jstat, GC日志, arthas dashboard              │
│ 数据库问题   │ SHOW PROCESSLIST, EXPLAIN, 慢查询日志        │
│ Redis 问题   │ redis-cli INFO, SLOWLOG, MONITOR             │
│ 接口问题     │ curl, Postman, 链路追踪                      │
└──────────────┴──────────────────────────────────────────────┘
```
