## 1. 加密算法分类

## 2. 对称加密算法

### 2.1 算法对比

| 算法 | 密钥长度 | 分组大小 | 安全性 | 性能 | 推荐场景 |
|------|---------|---------|--------|------|---------|
| AES-128 | 128位 | 128位 | 高 | 快 | 通用加密 |
| AES-256 | 256位 | 128位 | 更高 | 快 | 高安全要求 |
| DES | 56位 | 64位 | 低（已破解） | 慢 | 不推荐 |
| 3DES | 168位 | 64位 | 中 | 慢 | 遗留系统兼容 |
| ChaCha20 | 256位 | 流密码 | 高 | 极快 | 移动端/TLS |
| SM4 | 128位 | 128位 | 高 | 快 | 国密合规 |

### 2.2 AES 算法详解

```
AES 加密模式:

ECB（电子密码本）:
┌─────────┐ ┌─────────┐ ┌─────────┐
│ Block 1 │ │ Block 2 │ │ Block 3 │
└────┬────┘ └────┬────┘ └────┬────┘
     │           │           │
     ▼           ▼           ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│Encrypt  │ │Encrypt  │ │Encrypt  │
│Key      │ │Key      │ │Key      │
└────┬────┘ └────┬────┘ └────┬────┘
     │           │           │
     ▼           ▼           ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│Cipher 1 │ │Cipher 2 │ │Cipher 3 │
└─────────┘ └─────────┘ └─────────┘
问题: 相同明文 → 相同密文，不推荐

CBC（密码块链接）:
                IV
                │
                ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│ Block 1 │ │ Block 2 │ │ Block 3 │
└────┬────┘ └────┬────┘ └────┬────┘
     │           │           │
     ▼           │           │
   XOR           │           │
     │           │           │
     ▼           ▼           ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│Encrypt  │ │Encrypt  │ │Encrypt  │
│Key      │ │Key      │ │Key      │
└────┬────┘ └────┬────┘ └────┬────┘
     │           │           │
     ├──────────→│           │
     │           ├──────────→│
     ▼           ▼           ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│Cipher 1 │ │Cipher 2 │ │Cipher 3 │
└─────────┘ └─────────┘ └─────────┘
优点: 相同明文 → 不同密文（依赖IV）

GCM（伽罗瓦计数器）:
- 同时提供加密和认证（AEAD）
- 高性能，硬件加速
- 推荐用于 TLS 1.3
```

### 2.3 Java AES 实现

```java
import javax.crypto.Cipher;
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.util.Base64;

public class AESUtil {
    
    private static final int GCM_TAG_LENGTH = 128;
    private static final int GCM_IV_LENGTH = 12;
    
    /**
     * 生成 AES 密钥
     */
    public static SecretKey generateKey(int keySize) throws Exception {
        KeyGenerator keyGen = KeyGenerator.getInstance("AES");
        keyGen.init(keySize);
        return keyGen.generateKey();
    }
    
    /**
     * AES-GCM 加密（推荐）
     */
    public static byte[] encryptGCM(byte[] plaintext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        GCMParameterSpec spec = new GCMParameterSpec(GCM_TAG_LENGTH, iv);
        cipher.init(Cipher.ENCRYPT_MODE, key, spec);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * AES-GCM 解密
     */
    public static byte[] decryptGCM(byte[] ciphertext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        GCMParameterSpec spec = new GCMParameterSpec(GCM_TAG_LENGTH, iv);
        cipher.init(Cipher.DECRYPT_MODE, key, spec);
        return cipher.doFinal(ciphertext);
    }
    
    /**
     * AES-CBC 加密（兼容旧系统）
     */
    public static byte[] encryptCBC(byte[] plaintext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
        javax.crypto.spec.IvParameterSpec ivSpec = 
            new javax.crypto.spec.IvParameterSpec(iv);
        cipher.init(Cipher.ENCRYPT_MODE, key, ivSpec);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * 完整示例：加密 + Base64 编码
     */
    public static String encryptToBase64(String plaintext, String base64Key) 
            throws Exception {
        SecretKey key = new SecretKeySpec(
            Base64.getDecoder().decode(base64Key), "AES");
        byte[] iv = new byte[GCM_IV_LENGTH];
        new SecureRandom().nextBytes(iv);
        
        byte[] ciphertext = encryptGCM(plaintext.getBytes("UTF-8"), key, iv);
        
        // IV + 密文一起存储
        byte[] combined = new byte[iv.length + ciphertext.length];
        System.arraycopy(iv, 0, combined, 0, iv.length);
        System.arraycopy(ciphertext, 0, combined, iv.length, ciphertext.length);
        
        return Base64.getEncoder().encodeToString(combined);
    }
    
    /**
     * 完整示例：Base64 解码 + 解密
     */
    public static String decryptFromBase64(String base64Combined, String base64Key) 
            throws Exception {
        SecretKey key = new SecretKeySpec(
            Base64.getDecoder().decode(base64Key), "AES");
        byte[] combined = Base64.getDecoder().decode(base64Combined);
        
        byte[] iv = new byte[GCM_IV_LENGTH];
        byte[] ciphertext = new byte[combined.length - GCM_IV_LENGTH];
        System.arraycopy(combined, 0, iv, 0, iv.length);
        System.arraycopy(combined, iv.length, ciphertext, 0, ciphertext.length);
        
        byte[] plaintext = decryptGCM(ciphertext, key, iv);
        return new String(plaintext, "UTF-8");
    }
    
    public static void main(String[] args) throws Exception {
        // 生成密钥
        SecretKey key = generateKey(256);
        String base64Key = Base64.getEncoder().encodeToString(key.getEncoded());
        
        // 加密
        String plaintext = "Hello, AES-GCM!";
        String encrypted = encryptToBase64(plaintext, base64Key);
        System.out.println("加密: " + encrypted);
        
        // 解密
        String decrypted = decryptFromBase64(encrypted, base64Key);
        System.out.println("解密: " + decrypted);
    }
}
```

## 3. 非对称加密算法

### 3.1 RSA 算法

```
RSA 原理:

密钥生成:
1. 选择两个大素数 p, q
2. 计算 n = p × q
3. 计算 φ(n) = (p-1)(q-1)
4. 选择 e，满足 1 < e < φ(n) 且 gcd(e, φ(n)) = 1
5. 计算 d，满足 d × e ≡ 1 (mod φ(n))
6. 公钥: (n, e)
7. 私钥: (n, d)

加密: C = M^e mod n
解密: M = C^d mod n

RSA 密钥长度与安全强度:
┌────────────┬────────────┬────────────┐
│ 密钥长度   │ 安全强度   │ 推荐场景   │
├────────────┼────────────┼────────────┤
│ 1024 位    │ 80 位      │ 已不安全   │
│ 2048 位    │ 112 位     │ 当前最低   │
│ 3072 位    │ 128 位     │ 推荐       │
│ 4096 位    │ 140 位     │ 高安全     │
└────────────┴────────────┴────────────┘

RSA 填充模式:
- PKCS1Padding: 不推荐（存在攻击）
- OAEP (推荐): Optimal Asymmetric Encryption Padding
- OAEPWithSHA-256AndMGF1Padding: 最佳选择
```

### 3.2 ECC 椭圆曲线算法

```
ECC 优势:

相同安全强度下，密钥长度更短:
┌───────────┬──────────────┬─────────────┐
│ 安全强度  │ RSA 密钥长度 │ ECC 密钥长度│
├───────────┼──────────────┼─────────────┤
│ 80 位     │ 1024 位      │ 160 位      │
│ 112 位    │ 2048 位      │ 224 位      │
│ 128 位    │ 3072 位      │ 256 位      │
│ 192 位    │ 7680 位      │ 384 位      │
└───────────┴──────────────┴─────────────┘

ECC 性能对比（128位安全强度）:
- 密钥生成: ECC 比 RSA 快 10-100 倍
- 签名: ECC 比 RSA 快 10 倍
- 验证: RSA 比 ECC 快 2-10 倍
- 带宽: ECC 占用更少

常用椭圆曲线:
- P-256 (secp256r1): NIST 标准，TLS 1.3 默认
- secp256k1: 比特币/以太坊使用
- Curve25519: 高性能，Signal/SSH 使用
```

### 3.3 Java RSA/ECC 实现

```java
import java.security.*;
import java.security.spec.*;
import javax.crypto.Cipher;
import java.util.Base64;

public class RSAUtil {
    
    /**
     * 生成 RSA 密钥对
     */
    public static KeyPair generateKeyPair(int keySize) throws Exception {
        KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA");
        keyGen.initialize(keySize);
        return keyGen.generateKeyPair();
    }
    
    /**
     * RSA-OAEP 加密（推荐）
     */
    public static byte[] encryptOAEP(byte[] plaintext, PublicKey publicKey) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("RSA/ECB/OAEPWithSHA-256AndMGF1Padding");
        cipher.init(Cipher.ENCRYPT_MODE, publicKey);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * RSA-OAEP 解密
     */
    public static byte[] decryptOAEP(byte[] ciphertext, PrivateKey privateKey) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("RSA/ECB/OAEPWithSHA-256AndMGF1Padding");
        cipher.init(Cipher.DECRYPT_MODE, privateKey);
        return cipher.doFinal(ciphertext);
    }
    
    /**
     * RSA 签名（SHA256withRSA）
     */
    public static byte[] sign(byte[] data, PrivateKey privateKey) throws Exception {
        Signature signature = Signature.getInstance("SHA256withRSA");
        signature.initSign(privateKey);
        signature.update(data);
        return signature.sign();
    }
    
    /**
     * RSA 验签
     */
    public static boolean verify(byte[] data, byte[] signatureBytes, 
                                  PublicKey publicKey) throws Exception {
        Signature signature = Signature.getInstance("SHA256withRSA");
        signature.initVerify(publicKey);
        signature.update(data);
        return signature.verify(signatureBytes);
    }
    
    /**
     * 密钥序列化（Base64）
     */
    public static String publicKeyToBase64(PublicKey publicKey) {
        return Base64.getEncoder().encodeToString(publicKey.getEncoded());
    }
    
    public static String privateKeyToBase64(PrivateKey privateKey) {
        return Base64.getEncoder().encodeToString(privateKey.getEncoded());
    }
    
    /**
     * 从 Base64 恢复公钥
     */
    public static PublicKey publicKeyFromBase64(String base64) throws Exception {
        byte[] keyBytes = Base64.getDecoder().decode(base64);
        X509EncodedKeySpec spec = new X509EncodedKeySpec(keyBytes);
        return KeyFactory.getInstance("RSA").generatePublic(spec);
    }
    
    public static void main(String[] args) throws Exception {
        // 生成密钥对
        KeyPair keyPair = generateKeyPair(2048);
        
        // 加密解密
        String message = "Hello, RSA-OAEP!";
        byte[] encrypted = encryptOAEP(message.getBytes(), keyPair.getPublic());
        byte[] decrypted = decryptOAEP(encrypted, keyPair.getPrivate());
        System.out.println("解密: " + new String(decrypted));
        
        // 签名验签
        byte[] signature = sign(message.getBytes(), keyPair.getPrivate());
        boolean valid = verify(message.getBytes(), signature, keyPair.getPublic());
        System.out.println("签名验证: " + valid);
    }
}
```

## 4. 哈希算法

### 4.1 算法对比

| 算法 | 输出长度 | 安全性 | 性能 | 推荐场景 |
|------|---------|--------|------|---------|
| MD5 | 128位 | 已破解（碰撞） | 极快 | 仅用于校验，不用于安全 |
| SHA-1 | 160位 | 已破解（碰撞） | 快 | 不推荐 |
| SHA-256 | 256位 | 安全 | 快 | 通用推荐 |
| SHA-384 | 384位 | 安全 | 中 | 高安全要求 |
| SHA-512 | 512位 | 安全 | 中 | 高安全要求 |
| SHA3-256 | 256位 | 安全 | 中 | 新项目推荐 |
| SM3 | 256位 | 安全 | 快 | 国密合规 |

### 4.2 HMAC 消息认证码

```
HMAC (Hash-based Message Authentication Code):

原理:
HMAC(K, m) = H((K' ⊕ opad) || H((K' ⊕ ipad) || m))

其中:
H: 哈希函数（SHA-256）
K: 密钥
K': 密钥填充到块大小
m: 消息
ipad: 0x36 重复
opad: 0x5C 重复

作用:
- 验证消息完整性（防篡改）
- 验证消息来源（持有共享密钥）
- 常用于 API 签名、JWT
```

```java
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.util.Base64;

public class HMACUtil {
    
    /**
     * HMAC-SHA256 签名
     */
    public static String hmacSha256(String message, String secret) throws Exception {
        Mac mac = Mac.getInstance("HmacSHA256");
        SecretKeySpec keySpec = new SecretKeySpec(
            secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        mac.init(keySpec);
        byte[] hash = mac.doFinal(message.getBytes(StandardCharsets.UTF_8));
        return Base64.getEncoder().encodeToString(hash);
    }
    
    /**
     * HMAC-SHA256 验证
     */
    public static boolean verify(String message, String secret, 
                                  String expectedHmac) throws Exception {
        String actualHmac = hmacSha256(message, secret);
        return actualHmac.equals(expectedHmac);
    }
    
    /**
     * 生成 API 签名示例
     */
    public static String generateApiSignature(String method, String path, 
                                               String timestamp, String body,
                                               String apiSecret) throws Exception {
        // 拼接待签名字符串
        String signString = String.format("%s\n%s\n%s\n%s", 
            method, path, timestamp, body != null ? body : "");
        return hmacSha256(signString, apiSecret);
    }
    
    public static void main(String[] args) throws Exception {
        String message = "Hello, HMAC!";
        String secret = "my-secret-key";
        
        String hmac = hmacSha256(message, secret);
        System.out.println("HMAC: " + hmac);
        
        boolean valid = verify(message, secret, hmac);
        System.out.println("验证: " + valid);
    }
}
```

### 4.3 完整性校验实践

```java
import java.security.MessageDigest;
import java.nio.file.*;
import java.io.*;

public class HashUtil {
    
    /**
     * 计算文件 SHA-256
     */
    public static String sha256File(Path filePath) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        try (InputStream is = Files.newInputStream(filePath)) {
            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = is.read(buffer)) != -1) {
                digest.update(buffer, 0, bytesRead);
            }
        }
        byte[] hash = digest.digest();
        return bytesToHex(hash);
    }
    
    /**
     * 计算字符串哈希
     */
    public static String sha256(String input) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        byte[] hash = digest.digest(input.getBytes("UTF-8"));
        return bytesToHex(hash);
    }
    
    /**
     * 密码加盐哈希（演示用，生产请用 bcrypt/Argon2）
     */
    public static String hashPassword(String password, String salt) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        digest.update(salt.getBytes("UTF-8"));
        byte[] hash = digest.digest(password.getBytes("UTF-8"));
        
        // 多轮迭代增强安全性
        for (int i = 0; i < 10000; i++) {
            digest.reset();
            hash = digest.digest(hash);
        }
        
        return salt + ":" + bytesToHex(hash);
    }
    
    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            sb.append(String.format("%02x", b));
        }
        return sb.toString();
    }
    
    public static void main(String[] args) throws Exception {
        // 文件完整性校验
        Path path = Paths.get("example.txt");
        String hash = sha256File(path);
        System.out.println("文件 SHA-256: " + hash);
        
        // 密码哈希
        String password = "user-password";
        String salt = "random-salt-123";
        String hashed = hashPassword(password, salt);
        System.out.println("密码哈希: " + hashed);
    }
}
```

## 5. 数字签名与证书

### 5.1 数字签名原理

```
数字签名流程:

签名方（发送者）:
┌──────────┐
│  原文    │
└────┬─────┘
     │
     ▼
┌──────────┐
│  哈希    │ → 摘要（Digest）
└────┬─────┘
     │
     ▼
┌──────────┐
│ 私钥加密 │ → 签名（Signature）
└────┬─────┘
     │
     ▼
发送: 原文 + 签名

验签方（接收者）:
┌──────────┐     ┌──────────┐
│  原文    │     │  签名    │
└────┬─────┘     └────┬─────┘
     │                │
     ▼                ▼
┌──────────┐     ┌──────────┐
│  哈希    │     │ 公钥解密 │
└────┬─────┘     └────┬─────┘
     │                │
     └────────┬───────┘
              ▼
         摘要对比
              │
         ┌────┴────┐
         │  相同   │ → 签名有效，原文未被篡改
         └─────────┘

常用签名算法:
- RSA + SHA256: SHA256withRSA
- ECDSA + SHA256: SHA256withECDSA（推荐，更短签名）
- EdDSA: Ed25519（高性能）
```

### 5.2 证书与 PKI

```
X.509 证书结构:

Certificate:
├── Version: v3
├── Serial Number: 唯一序列号
├── Signature Algorithm: SHA256withRSA
├── Issuer: 签发者（CA）
├── Validity:
│   ├── Not Before: 生效时间
│   └── Not After: 过期时间
├── Subject: 持有者信息
│   ├── CN: Common Name（域名）
│   ├── O: Organization
│   └── C: Country
├── Subject Public Key Info:
│   ├── Algorithm: RSA/ECC
│   └── Public Key: 公钥
├── Extensions:
│   ├── Subject Alternative Name: 多域名
│   ├── Key Usage: 用途
│   └── Basic Constraints: 是否CA
└── Signature: CA 签名

证书类型:
DV (Domain Validation):   域名验证，最基础
OV (Organization):        组织验证，包含企业信息
EV (Extended):            扩展验证，地址栏绿色（已弃用）
```

### 5.3 TLS/SSL 握手流程

```
TLS 1.3 握手（简化）:

Client                              Server
  │                                    │
  │──── ClientHello ──────────────────→│
  │     - 支持的密码套件               │
  │     - 支持的 TLS 版本              │
  │     - 随机数                       │
  │                                    │
  │←─── ServerHello ──────────────────│
  │     - 选择的密码套件               │
  │     - 证书                         │
  │     - 随机数                       │
  │                                    │
  │     [Certificate]                  │
  │     [CertificateVerify]            │
  │     [Finished]                     │
  │                                    │
  │──── [Finished] ──────────────────→│
  │                                    │
  │←══════ 应用数据 ═══════════════════│
  │                                    │

TLS 1.3 优势:
- 1-RTT 握手（TLS 1.2 需要 2-RTT）
- 0-RTT 恢复（会话复用）
- 更安全的密码套件（移除不安全算法）
```

```
密钥生命周期管理:
```

```java
import org.springframework.security.crypto.encrypt.*;
import org.springframework.security.crypto.keygen.KeyGenerators;
import org.springframework.stereotype.Service;

@Service
public class EncryptionService {
    
    private final BytesEncryptor encryptor;
    private final StringEncryptor stringEncryptor;
    
    public EncryptionService() {
        // 生成密钥和盐
        String key = KeyGenerators.string().generateKey(); // 16字节
        String salt = KeyGenerators.string().generateKey(); // 16字节
        
        // AES-256-CBC 加密器
        this.encryptor = Encryptors.stronger("password", salt);
        
        // 字符串加密器
        this.stringEncryptor = Encryptors.text("password", salt);
    }
    
    /**
     * 加密敏感数据
     */
    public String encrypt(String plaintext) {
        return stringEncryptor.encrypt(plaintext);
    }
    
    /**
     * 解密敏感数据
     */
    public String decrypt(String ciphertext) {
        return stringEncryptor.decrypt(ciphertext);
    }
    
    /**
     * 加密字节数组
     */
    public byte[] encrypt(byte[] data) {
        return encryptor.encrypt(data);
    }
    
    public byte[] decrypt(byte[] encryptedData) {
        return encryptor.decrypt(encryptedData);
    }
}
```

### 6.3 API 签名实践

```java
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.time.Instant;
import java.util.Base64;
import java.util.Map;
import java.util.TreeMap;

public class ApiSignatureUtil {
    
    /**
     * 生成 API 请求签名
     * 
     * 签名规则:
     * 1. 按参数名排序
     * 2. 拼接参数
     * 3. 添加时间戳和随机数
     * 4. HMAC-SHA256 签名
     */
    public static String signRequest(String method, String path,
                                      Map<String, String> params,
                                      String body,
                                      String appKey,
                                      String appSecret) throws Exception {
        // 1. 添加公共参数
        long timestamp = Instant.now().getEpochSecond();
        String nonce = UUID.randomUUID().toString().replace("-", "");
        
        // 2. 参数排序
        TreeMap<String, String> sortedParams = new TreeMap<>(params);
        sortedParams.put("appKey", appKey);
        sortedParams.put("timestamp", String.valueOf(timestamp));
        sortedParams.put("nonce", nonce);
        
        // 3. 拼接待签名字符串
        StringBuilder signString = new StringBuilder();
        signString.append(method.toUpperCase()).append("\n");
        signString.append(path).append("\n");
        
        // 参数按 key=value&key=value 拼接
        sortedParams.forEach((k, v) -> {
            if (signString.length() > 0 && signString.charAt(signString.length() - 1) != '\n') {
                signString.append("&");
            }
            signString.append(k).append("=").append(v);
        });
        
        if (body != null && !body.isEmpty()) {
            signString.append("\n").append(body);
        }
        
        // 4. HMAC-SHA256 签名
        Mac mac = Mac.getInstance("HmacSHA256");
        SecretKeySpec keySpec = new SecretKeySpec(
            appSecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        mac.init(keySpec);
        byte[] hash = mac.doFinal(signString.toString().getBytes(StandardCharsets.UTF_8));
        
        return Base64.getEncoder().encodeToString(hash);
    }
    
    /**
     * 验证 API 响应签名
     */
    public static boolean verifyResponse(String responseBody,
                                          String signature,
                                          String appSecret) throws Exception {
        Mac mac = Mac.getInstance("HmacSHA256");
        SecretKeySpec keySpec = new SecretKeySpec(
            appSecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        mac.init(keySpec);
        byte[] hash = mac.doFinal(responseBody.getBytes(StandardCharsets.UTF_8));
        String expectedSignature = Base64.getEncoder().encodeToString(hash);
        
        return expectedSignature.equals(signature);
    }
}
```

### 6.4 敏感数据加密存储

```java
import javax.persistence.AttributeConverter;
import javax.persistence.Converter;

/**
 * JPA 实体字段加密转换器
 */
@Converter
public class EncryptedStringConverter implements AttributeConverter<String, String> {
    
    private final EncryptionService encryptionService;
    
    public EncryptedStringConverter() {
        this.encryptionService = ApplicationContextProvider
            .getApplicationContext()
            .getBean(EncryptionService.class);
    }
    
    @Override
    public String convertToDatabaseColumn(String attribute) {
        if (attribute == null) {
            return null;
        }
        return encryptionService.encrypt(attribute);
    }
    
    @Override
    public String convertToEntityAttribute(String dbData) {
        if (dbData == null) {
            return null;
        }
        return encryptionService.decrypt(dbData);
    }
}

// 使用示例
@Entity
@Table(name = "users")
public class User {
    
    @Id
    private Long id;
    
    private String username;
    
    @Convert(converter = EncryptedStringConverter.class)
    private String idCardNumber;  // 身份证号，加密存储
    
    @Convert(converter = EncryptedStringConverter.class)
    private String phoneNumber;   // 手机号，加密存储
    
    private String email;         // 邮箱，可不加密
}
```

## 7. 安全检查清单

```
加密算法选择 Checklist:

□ 对称加密:
  - 使用 AES-256-GCM（首选）或 AES-256-CBC
  - 禁止使用 DES、RC4、ECB 模式
  - IV/Nonce 必须随机生成，不可复用

□ 非对称加密:
  - RSA 密钥长度 >= 2048 位（推荐 3072）
  - 使用 OAEP 填充（非 PKCS1）
  - 优先考虑 ECC（性能更好）

□ 哈希算法:
  - 禁止使用 MD5、SHA-1 用于安全场景
  - 使用 SHA-256 或 SHA-3
  - 密码存储使用 bcrypt/Argon2（非 SHA）

□ 密钥管理:
  - 密钥不可硬编码在代码中
  - 使用环境变量或 KMS 管理密钥
  - 定期轮换密钥
  - 密钥访问需要审计日志

□ 传输安全:
  - 强制使用 HTTPS（HSTS）
  - TLS 版本 >= 1.2（推荐 1.3）
  - 禁用弱密码套件

□ 数据存储:
  - 敏感字段加密存储（手机号、身份证）
  - 密码使用 bcrypt/Argon2 加盐哈希
  - 加密数据完整性校验
```
