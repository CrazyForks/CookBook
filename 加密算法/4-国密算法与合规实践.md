# 国密算法与合规实践

## 1. 国密算法概述

```
国密算法体系（国家密码管理局发布）:

┌─────────────────────────────────────────────────────────────┐
│                      国密算法                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────┐    ┌───────────────┐    ┌─────────────┐ │
│  │   SM2         │    │   SM3         │    │   SM4       │ │
│  │  (非对称加密) │    │  (哈希算法)   │    │  (对称加密) │ │
│  ├───────────────┤    ├───────────────┤    ├─────────────┤ │
│  │ 椭圆曲线     │    │ 256位输出     │    │ 128位密钥   │ │
│  │ 加密/签名    │    │ 类似SHA-256   │    │ 128位分组   │ │
│  │ 密钥交换     │    │ 消息认证码    │    │ CBC/CTR模式 │ │
│  └───────────────┘    └───────────────┘    └─────────────┘ │
│                                                             │
│  应用场景:                                                  │
│  SM2: 数字签名、密钥交换、身份认证（替代RSA）               │
│  SM3: 完整性校验、密码存储、数字签名（替代SHA-256）         │

│                                                             │
│  合规要求:                                                  │
│  - 金融行业: 银行、证券、保险必须使用国密                   │
│  - 政务系统: 政府、央企、事业单位必须使用                   │
│  - 关键基础设施: 能源、交通、通信建议使用                   │
└─────────────────────────────────────────────────────────────┘
```

## 2. SM2 椭圆曲线算法

### 2.1 算法原理

```
SM2 曲线参数:

曲线方程: y² = x³ + ax + b (mod p)

参数:
p  = FFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF00000000FFFFFFFFFFFFFFFF
a  = FFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF00000000FFFFFFFFFFFFFFFC
b  = 28E9FA9E9D9F5E344D5A9E4BCF6509A7F39789F515AB8F92DDBCBD414D940E93
n  = FFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFF7203DF6B21C6052B53BBF40939D54123
Gx = 32C4AE2C1F1981195F9904466A39C9948FE30BBFF2660BE1715A4589334C74C7
Gy = BC3736A2F4F6779C59BDCEE36B692153D0A9877CC62A474002DF32E52139F0A0

密钥对:
私钥 d: 256位随机整数
公钥 P: d × G（椭圆曲线点乘）

与 ECC 对比:
┌─────────┬──────────────┬──────────────┐
│ 特性    │ SM2          │ ECC (P-256)  │
├─────────┼──────────────┼──────────────┤
│ 曲线    │ 自主设计     │ NIST 标准    │
│ 安全性  │ 128 位       │ 128 位       │
│ 性能    │ 相当         │ 相当         │
│ 合规    │ 国密认证     │ 无           │
│ 标准    │ GM/T 0003    │ FIPS 186-4   │
└─────────┴──────────────┴──────────────┘
```

### 2.2 Java 实现

```java
import org.bouncycastle.jce.provider.BouncyCastleProvider;
import java.security.*;
import java.security.spec.*;
import javax.crypto.Cipher;

public class SM2Util {
    
    static {
        // 注册 BouncyCastle 提供者
        Security.addProvider(new BouncyCastleProvider());
    }
    
    /**
     * 生成 SM2 密钥对
     */
    public static KeyPair generateKeyPair() throws Exception {
        KeyPairGenerator keyGen = KeyPairGenerator.getInstance("EC", "BC");
        ECGenParameterSpec spec = new ECGenParameterSpec("sm2p256v1");
        keyGen.initialize(spec, new SecureRandom());
        return keyGen.generateKeyPair();
    }
    
    /**
     * SM2 加密
     */
    public static byte[] encrypt(byte[] plaintext, PublicKey publicKey) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM2", "BC");
        cipher.init(Cipher.ENCRYPT_MODE, publicKey);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * SM2 解密
     */
    public static byte[] decrypt(byte[] ciphertext, PrivateKey privateKey) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM2", "BC");
        cipher.init(Cipher.DECRYPT_MODE, privateKey);
        return cipher.doFinal(ciphertext);
    }
    
    /**
     * SM2 签名
     */
    public static byte[] sign(byte[] data, PrivateKey privateKey) 
            throws Exception {
        Signature signature = Signature.getInstance("SM3withSM2", "BC");
        signature.initSign(privateKey);
        signature.update(data);
        return signature.sign();
    }
    
    /**
     * SM2 验签
     */
    public static boolean verify(byte[] data, byte[] signatureBytes, 
                                  PublicKey publicKey) throws Exception {
        Signature signature = Signature.getInstance("SM3withSM2", "BC");
        signature.initVerify(publicKey);
        signature.update(data);
        return signature.verify(signatureBytes);
    }
    
    /**
     * 密钥序列化
     */
    public static String publicKeyToHex(PublicKey publicKey) {
        return bytesToHex(publicKey.getEncoded());
    }
    
    public static String privateKeyToHex(PrivateKey privateKey) {
        return bytesToHex(privateKey.getEncoded());
    }
    
    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            sb.append(String.format("%02x", b));
        }
        return sb.toString();
    }
    
    public static void main(String[] args) throws Exception {
        // 生成密钥对
        KeyPair keyPair = generateKeyPair();
        System.out.println("公钥: " + publicKeyToHex(keyPair.getPublic()));
        System.out.println("私钥: " + privateKeyToHex(keyPair.getPrivate()));
        
        // 加密解密
        String message = "Hello, SM2!";
        byte[] encrypted = encrypt(message.getBytes(), keyPair.getPublic());
        byte[] decrypted = decrypt(encrypted, keyPair.getPrivate());
        System.out.println("解密: " + new String(decrypted));
        
        // 签名验签
        byte[] signature = sign(message.getBytes(), keyPair.getPrivate());
        boolean valid = verify(message.getBytes(), signature, keyPair.getPublic());
        System.out.println("签名验证: " + valid);
    }
}
```

## 3. SM3 哈希算法

### 3.1 算法特点

```
SM3 特性:

输出: 256位（32字节）
安全性: 128位抗碰撞
性能: 与 SHA-256 相当

与 SHA-256 对比:
┌─────────┬──────────────┬──────────────┐
│ 特性    │ SM3          │ SHA-256      │
├─────────┼──────────────┼──────────────┤
│ 输出    │ 256 位       │ 256 位       │
│ 安全性  │ 128 位       │ 128 位       │
│ 结构    │ Merkle-Damgård│ Merkle-Damgård│
│ 压缩函数│ 自主设计     │ SHA 系列     │
│ 合规    │ 国密认证     │ 无           │
└─────────┴──────────────┴──────────────┘

SM3 应用场景:
1. 数字签名（配合 SM2）
2. 消息认证码（HMAC-SM3）
3. 密码存储（加盐哈希）
4. 完整性校验
```

### 3.2 Java 实现

```java
import org.bouncycastle.crypto.digests.SM3Digest;
import org.bouncycastle.crypto.macs.HMac;
import org.bouncycastle.crypto.params.KeyParameter;
import java.nio.charset.StandardCharsets;

public class SM3Util {
    
    /**
     * SM3 哈希
     */
    public static byte[] hash(byte[] data) {
        SM3Digest digest = new SM3Digest();
        digest.update(data, 0, data.length);
        byte[] result = new byte[digest.getDigestSize()];
        digest.doFinal(result, 0);
        return result;
    }
    
    /**
     * SM3 哈希（字符串）
     */
    public static String hashToHex(String input) {
        byte[] hash = hash(input.getBytes(StandardCharsets.UTF_8));
        return bytesToHex(hash);
    }
    
    /**
     * HMAC-SM3
     */
    public static byte[] hmac(byte[] data, byte[] key) {
        HMac hmac = new HMac(new SM3Digest());
        hmac.init(new KeyParameter(key));
        hmac.update(data, 0, data.length);
        byte[] result = new byte[hmac.getMacSize()];
        hmac.doFinal(result, 0);
        return result;
    }
    
    /**
     * HMAC-SM3（字符串版本）
     */
    public static String hmacToHex(String message, String secret) {
        byte[] key = secret.getBytes(StandardCharsets.UTF_8);
        byte[] data = message.getBytes(StandardCharsets.UTF_8);
        byte[] hmac = hmac(data, key);
        return bytesToHex(hmac);
    }
    
    /**
     * 文件 SM3 哈希
     */
    public static String hashFile(Path filePath) throws Exception {
        SM3Digest digest = new SM3Digest();
        try (InputStream is = Files.newInputStream(filePath)) {
            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = is.read(buffer)) != -1) {
                digest.update(buffer, 0, bytesRead);
            }
        }
        byte[] result = new byte[digest.getDigestSize()];
        digest.doFinal(result, 0);
        return bytesToHex(result);
    }
    
    /**
     * 密码加盐哈希
     */
    public static String hashPassword(String password, String salt) {
        String saltedPassword = salt + password;
        byte[] hash = hash(saltedPassword.getBytes(StandardCharsets.UTF_8));
        
        // 多轮迭代
        for (int i = 0; i < 10000; i++) {
            hash = hash(hash);
        }
        
        return salt + ":" + bytesToHex(hash);
    }
    
    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            sb.append(String.format("%02x", b));
        }
        return sb.toString();
    }
    
    public static void main(String[] args) {
        // 基本哈希
        String input = "Hello, SM3!";
        System.out.println("SM3 哈希: " + hashToHex(input));
        
        // HMAC
        String secret = "my-secret-key";
        System.out.println("HMAC-SM3: " + hmacToHex(input, secret));
        
        // 密码哈希
        String password = "user-password";
        String salt = "random-salt";
        System.out.println("密码哈希: " + hashPassword(password, salt));
    }
}
```

## 4. SM4 对称加密算法

### 4.1 算法特点

```
SM4 特性:

密钥长度: 128位
分组大小: 128位
结构: Feistel 网络
轮数: 32 轮

与 AES 对比:
┌─────────┬──────────────┬──────────────┐
│ 特性    │ SM4          │ AES-128      │
├─────────┼──────────────┼──────────────┤
│ 密钥    │ 128 位       │ 128 位       │
│ 分组    │ 128 位       │ 128 位       │
│ 结构    │ Feistel      │ SPN          │
│ 轮数    │ 32 轮        │ 10 轮        │
│ 安全性  │ 128 位       │ 128 位       │
│ 合规    │ 国密认证     │ 无           │
└─────────┴──────────────┴──────────────┘

SM4 模式:
- ECB: 电子密码本（不推荐）
- CBC: 密码块链接（推荐）
- CTR: 计数器模式（推荐，支持并行）
- GCM: 伽罗瓦计数器（推荐，带认证）
```

### 4.2 Java 实现

```java
import org.bouncycastle.jce.provider.BouncyCastleProvider;
import javax.crypto.Cipher;
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import javax.crypto.spec.IvParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.security.Security;

public class SM4Util {
    
    static {
        Security.addProvider(new BouncyCastleProvider());
    }
    
    /**
     * 生成 SM4 密钥
     */
    public static SecretKey generateKey() throws Exception {
        KeyGenerator keyGen = KeyGenerator.getInstance("SM4", "BC");
        keyGen.init(128);
        return keyGen.generateKey();
    }
    
    /**
     * SM4-CBC 加密
     */
    public static byte[] encryptCBC(byte[] plaintext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM4/CBC/PKCS5Padding", "BC");
        IvParameterSpec ivSpec = new IvParameterSpec(iv);
        cipher.init(Cipher.ENCRYPT_MODE, key, ivSpec);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * SM4-CBC 解密
     */
    public static byte[] decryptCBC(byte[] ciphertext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM4/CBC/PKCS5Padding", "BC");
        IvParameterSpec ivSpec = new IvParameterSpec(iv);
        cipher.init(Cipher.DECRYPT_MODE, key, ivSpec);
        return cipher.doFinal(ciphertext);
    }
    
    /**
     * SM4-GCM 加密（带认证）
     */
    public static byte[] encryptGCM(byte[] plaintext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
        GCMParameterSpec spec = new GCMParameterSpec(128, iv);
        cipher.init(Cipher.ENCRYPT_MODE, key, spec);
        return cipher.doFinal(plaintext);
    }
    
    /**
     * SM4-GCM 解密
     */
    public static byte[] decryptGCM(byte[] ciphertext, SecretKey key, byte[] iv) 
            throws Exception {
        Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
        GCMParameterSpec spec = new GCMParameterSpec(128, iv);
        cipher.init(Cipher.DECRYPT_MODE, key, spec);
        return cipher.doFinal(ciphertext);
    }
    
    /**
     * 密钥序列化
     */
    public static String keyToHex(SecretKey key) {
        return bytesToHex(key.getEncoded());
    }
    
    public static SecretKey keyFromHex(String hex) {
        byte[] keyBytes = hexToBytes(hex);
        return new SecretKeySpec(keyBytes, "SM4");
    }
    
    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            sb.append(String.format("%02x", b));
        }
        return sb.toString();
    }
    
    private static byte[] hexToBytes(String hex) {
        int len = hex.length();
        byte[] data = new byte[len / 2];
        for (int i = 0; i < len; i += 2) {
            data[i / 2] = (byte) ((Character.digit(hex.charAt(i), 16) << 4)
                + Character.digit(hex.charAt(i + 1), 16));
        }
        return data;
    }
    
    public static void main(String[] args) throws Exception {
        // 生成密钥
        SecretKey key = generateKey();
        System.out.println("密钥: " + keyToHex(key));
        
        // CBC 模式
        byte[] iv = new byte[16];
        new SecureRandom().nextBytes(iv);
        
        String message = "Hello, SM4!";
        byte[] encrypted = encryptCBC(message.getBytes(), key, iv);
        byte[] decrypted = decryptCBC(encrypted, key, iv);
        System.out.println("CBC 解密: " + new String(decrypted));
        
        // GCM 模式
        byte[] gcmEncrypted = encryptGCM(message.getBytes(), key, iv);
        byte[] gcmDecrypted = decryptGCM(gcmEncrypted, key, iv);
        System.out.println("GCM 解密: " + new String(gcmDecrypted));
    }
}
```

## 5. 国密 TLS 配置

### 5.1 Nginx 配置

```nginx
# nginx.conf - 国密 TLS 配置

# 加载国密模块
# 需要编译时添加 --with-stream_ssl_module 和国密 SSL 库

server {
    listen 443 ssl;
    server_name example.com;
    
    # 国密证书
    ssl_certificate      /etc/nginx/ssl/sm2_server.crt;
    ssl_certificate_key  /etc/nginx/ssl/sm2_server.key;
    
    # 双证书（RSA + SM2）
    # ssl_certificate      /etc/nginx/ssl/server_rsa.crt;
    # ssl_certificate_key  /etc/nginx/ssl/server_rsa.key;
    # ssl_certificate      /etc/nginx/ssl/server_sm2.crt;
    # ssl_certificate_key  /etc/nginx/ssl/server_sm2.key;
    
    # 国密 TLS 协议
    ssl_protocols GMv1 TLSv1.2 TLSv1.3;
    
    # 国密密码套件
    ssl_ciphers SM2-WITH-SM4-SM3:ECDHE-SM2-WITH-SM4-SM3;
    
    # 其他配置
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;
    
    location / {
        proxy_pass http://backend;
    }
}
```

import org.springframework.boot.web.embedded.tomcat.TomcatServletWebServerFactory;

        };
    }

## 6. 合规检查清单

```
国密合规 Checklist:

□ 算法合规:
  - 数字签名使用 SM2withSM3
  - 哈希算法使用 SM3
  - 对称加密使用 SM4-CBC 或 SM4-GCM
  - 密钥交换使用 SM2 密钥协商

□ 证书合规:
  - 使用国密 CA 签发的证书
  - 证书格式符合 GM/T 0015
  - 证书链完整可验证

□ 协议合规:
  - TLS 使用 GM/T 0024 标准
  - 支持双证书机制（RSA + SM2）
  - 协议版本 GMv1 或 TLS 1.2+

□ 密钥管理:
  - 密钥生成符合 GM/T 0009
  - 密钥存储使用硬件加密机
  - 密钥备份和恢复机制
  - 密钥定期轮换

□ 安全审计:
  - 记录所有加密操作
  - 保留审计日志不少于 6 个月
  - 定期进行安全评估

□ 产品认证:
  - 通过国密局认证（商用密码产品型号证书）
  - 检测报告编号有效
  - 认证范围覆盖使用场景
```

## 7. 常见问题

### Q1: 国密和国际算法可以混用吗？

A: 可以，但需要注意：
1. 合规场景建议纯国密
2. 兼容场景可使用双证书（RSA + SM2）
3. 混用时需明确安全边界

### Q2: 性能影响大吗？

A: 影响较小：
1. SM2 与 ECC 性能相当
2. SM3 与 SHA-256 性能相当
3. SM4 与 AES-128 性能相当
4. 硬件加速可进一步提升

### Q3: 如何获取国密证书？

A: 途径：
1. 商业 CA：沃通、CFCA、天威诚信
2. 自建 CA：使用国密工具链
3. 测试环境：自签名证书

### Q4: 浏览器兼容性如何？

A: 现状：
1. 国产浏览器：360、搜狗、QQ 支持
2. Chrome/Firefox：需要插件
3. 移动端：微信、支付宝支持
4. 建议：双证书兼容方案
