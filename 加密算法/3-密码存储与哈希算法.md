# 密码存储与哈希算法

## 1. 为什么不能用 MD5/SHA 存储密码？

```
不安全的密码存储方式:

方式一：明文存储
密码: "123456"
风险: 数据库泄露 → 密码直接暴露

方式二：MD5/SHA 哈希（无盐）
密码: "123456"
MD5:  e10adc3949ba59abbe56e057f20f883e
风险:
1. 彩虹表攻击：预先计算常见密码的哈希值
2. 碰撞攻击：不同密码产生相同哈希
3. 相同密码 → 相同哈希（可批量破解）

方式三：加盐哈希（盐过短/固定）
密码: "123456" + 盐: "abc"
SHA256: hash("123456abc")
风险: 盐被泄露 → 可针对性破解

安全方式：专用密码哈希算法
bcrypt: $2a$10$N9qo8uLOickgx2ZMRZoMye.IjqoGh/H...
Argon2: $argon2id$v=19$m=65536,t=3,p=4$c29tZXNhbHQ$...
```

## 2. 密码哈希算法对比

| 算法 | 安全性 | 性能 | 内存消耗 | 推荐度 |
|------|--------|------|---------|--------|
| MD5 | 已破解 | 极快 | 低 | ❌ 不推荐 |
| SHA-256 | 不适合密码 | 快 | 低 | ❌ 不推荐 |
| bcrypt | 安全 | 慢（故意） | 中 | ✅ 推荐 |
| scrypt | 安全 | 慢 | 高 | ✅ 推荐 |
| Argon2 | 最安全 | 可调 | 可调 | ✅ 首选 |

### 2.1 bcrypt 原理

```
bcrypt 结构:

$2a$10$N9qo8uLOickgx2ZMRZoMye.IjqoGh/H...

$2a$    版本标识
10$     cost factor（2^10 = 1024 轮迭代）
N9qo8uLOickgx2ZMRZoMye.  盐（22字符 Base64）
IjqoGh/H...              哈希结果（31字符）

特点:
1. 自动加盐（盐嵌入哈希结果）
2. 可调节 cost factor（迭代次数）
3. 慢哈希设计（防暴力破解）
4. 60 字符固定长度输出

成本因子与耗时:
cost=10: ~100ms
cost=12: ~400ms
cost=14: ~1.6s
建议: 根据服务器性能选择，登录耗时 200-500ms 可接受
```

### 2.2 Argon2 原理

```
Argon2 三种变体:

Argon2d: 最大化抵抗 GPU 破解
         使用数据依赖内存访问
         适合：加密货币、密钥派生

Argon2i: 最大化抵抗侧信道攻击
         使用数据独立内存访问
         适合：密码哈希

Argon2id: 混合模式（推荐）
          先 i 后 d
          兼顾两种攻击防护

参数说明:
m: 内存消耗（KB）
t: 迭代次数
p: 并行度
盐: 随机盐值

示例: $argon2id$v=19$m=65536,t=3,p=4$c29tZXNhbHQ$RdescudvJCsgt3ub+b+dXWJ...
```

## 3. Java 实现

### 3.1 Spring Security BCrypt

```java
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;

public class PasswordHashingExample {
    
    public static void main(String[] args) {
        // 创建 BCrypt 编码器（默认 cost=10）
        PasswordEncoder encoder = new BCryptPasswordEncoder();
        
        // 自定义 cost factor
        PasswordEncoder strongEncoder = new BCryptPasswordEncoder(12);
        
        String password = "user-password-123";
        
        // 哈希密码
        String hash = encoder.encode(password);
        System.out.println("BCrypt 哈希: " + hash);
        // 输出: $2a$10$N9qo8uLOickgx2ZMRZoMye.IjqoGh/H...
        
        // 验证密码
        boolean matches = encoder.matches(password, hash);
        System.out.println("密码匹配: " + true);  // true
        
        // 错误密码验证
        boolean wrong = encoder.matches("wrong-password", hash);
        System.out.println("错误密码: " + false);  // false
        
        // 每次哈希结果不同（因为随机盐）
        String hash2 = encoder.encode(password);
        System.out.println("两次哈希不同: " + !hash.equals(hash2));  // true
        System.out.println("但都能验证: " + encoder.matches(password, hash2));  // true
    }
}
```

```java
import de.mkammerer.argon2.Argon2;
import de.mkammerer.argon2.Argon2Factory;

public class Argon2Example {
    
    public static void main(String[] args) {
        // 创建 Argon2id 实例
        Argon2 argon2 = Argon2Factory.create(Argon2Factory.Argon2Types.ARGON2id);
        
        String password = "user-password-123";
        
        // 哈希密码（推荐参数）
        // m=65536 (64MB), t=3 (3次迭代), p=4 (4个并行线程)
        String hash = argon2.hash(3, 65536, 4, password.toCharArray());
        System.out.println("Argon2 哈希: " + hash);
        
        // 验证密码
        boolean matches = argon2.verify(hash, password.toCharArray());
        System.out.println("密码匹配: " + matches);  // true
        
        // 错误密码验证
        boolean wrong = argon2.verify(hash, "wrong-password".toCharArray());
        System.out.println("错误密码: " + wrong);  // false
        
        // 需要重新哈希（参数变更时）
        if (argon2.needsRehash(hash, 4, 65536, 4)) {
            String newHash = argon2.hash(4, 65536, 4, password.toCharArray());
            System.out.println("重新哈希: " + newHash);
        }
    }
}
```

### 3.3 Spring Security 集成

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.crypto.argon2.Argon2PasswordEncoder;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;

@Configuration
public class PasswordConfig {
    
    /**
     * BCrypt 编码器（通用推荐）
     */
    @Bean
    public PasswordEncoder bcryptPasswordEncoder() {
        return new BCryptPasswordEncoder(12);
    }
    
    /**
     * Argon2 编码器（高安全场景）
     */
    @Bean
    public PasswordEncoder argon2PasswordEncoder() {
        int saltLength = 16;      // 盐长度
        int hashLength = 32;      // 哈希长度
        int parallelism = 4;      // 并行度
        int memory = 65536;       // 内存 64MB
        int iterations = 3;       // 迭代次数
        
        return new Argon2PasswordEncoder(saltLength, hashLength, 
            parallelism, memory, iterations);
    }
}

// UserDetailsService 实现
@Service
public class CustomUserDetailsService implements UserDetailsService {
    
    private final UserRepository userRepository;
    private final PasswordEncoder passwordEncoder;
    
    @Override
    public UserDetails loadUserByUsername(String username) 
            throws UsernameNotFoundException {
        User user = userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("用户不存在"));
        
        return User.builder()
            .username(user.getUsername())
            .password(user.getPassword())  // 数据库中存储的哈希值
            .roles(user.getRoles())
            .build();
    }
    
    /**
     * 注册用户时哈希密码
     */
    public void registerUser(RegisterRequest request) {
        User user = new User();
        user.setUsername(request.getUsername());
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        userRepository.save(user);
    }
}
```

## 4. 密码策略

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.provisioning.InMemoryUserDetailsManager;

@Configuration
public class PasswordPolicyConfig {
    
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);
    }
    
    /**
     * 密码强度验证
     */
    public static class PasswordValidator {
        
        private static final int MIN_LENGTH = 8;
        private static final int MAX_LENGTH = 128;
        
        public static ValidationResult validate(String password) {
            if (password == null || password.isEmpty()) {
                return ValidationResult.failure("密码不能为空");
            }
            
            if (password.length() < MIN_LENGTH) {
                return ValidationResult.failure("密码长度不能少于" + MIN_LENGTH + "位");
            }
            
            if (password.length() > MAX_LENGTH) {
                return ValidationResult.failure("密码长度不能超过" + MAX_LENGTH + "位");
            }
            
            // 检查复杂度
            boolean hasUpper = false, hasLower = false;
            boolean hasDigit = false, hasSpecial = false;
            
            for (char c : password.toCharArray()) {
                if (Character.isUpperCase(c)) hasUpper = true;
                else if (Character.isLowerCase(c)) hasLower = true;
                else if (Character.isDigit(c)) hasDigit = true;
                else hasSpecial = true;
            }
            
            int complexity = 0;
            if (hasUpper) complexity++;
            if (hasLower) complexity++;
            if (hasDigit) complexity++;
            if (hasSpecial) complexity++;
            
            if (complexity < 3) {
                return ValidationResult.failure("密码需包含大小写字母、数字、特殊字符中的至少3种");
            }
            
            // 检查常见密码
            if (isCommonPassword(password)) {
                return ValidationResult.failure("密码过于简单，请使用更复杂的密码");
            }
            
            return ValidationResult.success();
        }
        
        private static boolean isCommonPassword(String password) {
            // 常见密码列表（实际应使用更大的词库）
            Set<String> commonPasswords = Set.of(
                "123456", "password", "12345678", "qwerty", "123456789",
                "12345", "1234", "111111", "1234567", "dragon",
                "123123", "baseball", "abc123", "football", "monkey"
            );
            return commonPasswords.contains(password.toLowerCase());
        }
    }
    
    public static class ValidationResult {
        private final boolean valid;
        private final String message;
        
        private ValidationResult(boolean valid, String message) {
            this.valid = valid;
            this.message = message;
        }
        
        public static ValidationResult success() {
            return new ValidationResult(true, null);
        }
        
        public static ValidationResult failure(String message) {
            return new ValidationResult(false, message);
        }
        
        public boolean isValid() { return valid; }
        public String getMessage() { return message; }
    }
}
```

## 5. 密码轮换策略

```java
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;

@Service
public class PasswordRotationService {
    
    // 当前使用的编码器
    private final PasswordEncoder currentEncoder = new BCryptPasswordEncoder(12);
    
    // 旧版本编码器（用于验证旧密码）
    private final PasswordEncoder legacyEncoder = new BCryptPasswordEncoder(10);
    
    /**
     * 验证密码（支持旧版本）
     */
    public PasswordVerificationResult verifyPassword(String rawPassword, 
                                                      String storedHash) {
        // 尝试当前版本验证
        if (currentEncoder.matches(rawPassword, storedHash)) {
            // 检查是否需要升级
            if (needsUpgrade(storedHash)) {
                return PasswordVerificationResult.NEEDS_UPGRADE;
            }
            return PasswordVerificationResult.VALID;
        }
        
        // 尝试旧版本验证
        if (legacyEncoder.matches(rawPassword, storedHash)) {
            return PasswordVerificationResult.VALID_LEGACY_NEEDS_UPGRADE;
        }
        
        return PasswordVerificationResult.INVALID;
    }
    
    /**
     * 哈希密码
     */
    public String hashPassword(String rawPassword) {
        return currentEncoder.encode(rawPassword);
    }
    
    /**
     * 检查是否需要升级哈希
     */
    private boolean needsUpgrade(String storedHash) {
        // 检查 BCrypt 版本和 cost factor
        if (storedHash.startsWith("$2a$10$") || storedHash.startsWith("$2b$10$")) {
            // cost=10 可以考虑升级到 12
            return true;
        }
        return false;
    }
    
    public enum PasswordVerificationResult {
        VALID,                          // 密码正确，无需升级
        VALID_LEGACY_NEEDS_UPGRADE,    // 密码正确，需要升级
        NEEDS_UPGRADE,                  // 密码正确，需要升级哈希
        INVALID                         // 密码错误
    }
}

// 登录时自动升级密码
@Service
public class LoginService {
    
    private final PasswordRotationService passwordService;
    private final UserRepository userRepository;
    
    public boolean login(String username, String password) {
        User user = userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("用户不存在"));
        
        PasswordVerificationResult result = 
            passwordService.verifyPassword(password, user.getPasswordHash());
        
        switch (result) {
            case VALID:
                return true;
                
            case VALID_LEGACY_NEEDS_UPGRADE:
            case NEEDS_UPGRADE:
                // 自动升级密码哈希
                String newHash = passwordService.hashPassword(password);
                user.setPasswordHash(newHash);
                userRepository.save(user);
                return true;
                
            case INVALID:
                return false;
                
            default:
                return false;
        }
    }
}
```

## 6. 最佳实践总结

```
密码存储 Checklist:

□ 使用专用密码哈希算法:
  - 首选 Argon2id
  - 备选 bcrypt (cost >= 10)
  - 绝不使用 MD5/SHA-1/SHA-256

□ 合理设置参数:
  - bcrypt: cost=10-12（登录耗时 200-500ms）
  - Argon2id: m=64MB, t=3, p=4

□ 密码策略:
  - 最小长度 8 位
  - 复杂度要求（至少3种字符）
  - 禁止常见密码
  - 定期更换（90天）

□ 安全措施:
  - 传输加密（HTTPS）
  - 限制登录尝试次数
  - 记录安全日志
  - 密码历史记录（防止重复使用）

□ 密码轮换:
  - 支持多版本哈希验证
  - 登录时自动升级旧哈希
  - 优雅降级处理
```
